# Harsh - Full-Stack Python Developer Portfolio

A modern, responsive portfolio website built with Next.js, React, and Tailwind CSS.

## Features

- 🎨 Modern, responsive design
- 🚀 Built with Next.js 14 and TypeScript
- 💼 Professional sections: Hero, About, Skills, Projects, Resume, Contact
- 📱 Mobile-first responsive design
- 🎭 Interactive animations and smooth scrolling
- 📧 Contact form with validation

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Frontend**: React, Next.js, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Testing

- Unit tests with Jest and React Testing Library
- Integration tests with Cypress
- Linting with ESLint and Prettier
- Run all tests:

### For running all tests

```bash
npx vitest run
```

#### OR

```bash
npm test
npm run test
```

### For Single Test File

```bash
npx vitest run FileName.test.tsx
```

```bash
# For linting the codebase
npm run lint
```

```bash
# For formatting the codebase
npm run format
```
